# Cybersecurity Projects

A collection of hands-on cybersecurity projects focused on network defense, traffic analysis, and threat detection. Built while learning the fundamentals of blue team operations, intrusion detection, and secure networking.

---

## Projects

### 1. Network Intrusion Detection System (NIDS)
A working NIDS built with **Snort** on Arch Linux. Detects ICMP traffic using custom rules and visualizes network activity in real time.

**Tools:** Snort, EtherApe, Wireshark, Arch Linux  
**Skills:** Rule creation, traffic monitoring, packet analysis, Linux troubleshooting

[`nids/`](./NIDS)

---

### 2. Python Network Sniffer
A Python-based packet sniffer using **Scapy** that captures live network traffic and displays source/destination IPs, protocols, and port information.

**Tools:** Python, Scapy  
**Skills:** Packet capture, protocol analysis, socket programming

[`networksniffer/`](./NetworkSniffer)
